# Mandubi - CRM Application for Medical Representatives

تطبيق إدارة علاقات العملاء (CRM) مخصص للمندوبين الطبيين (Medical Representatives).

## 📋 الميزات الرئيسية

### 1️⃣ لوحة التحكم (Dashboard)
- عرض الزيارات المقررة اليوم
- عرض الزيارات المتأخرة مع تحذيرات
- إحصائيات سريعة ملونة
- زر عائم سريع لإضافة زيارة جديدة

### 2️⃣ دليل الأطباء (Doctors Directory)
- قائمة شاملة بجميع الأطباء
- تصفية متقدمة حسب الفئة (A, B, C)
- بحث فوري عن الأطباء
- عرض تفاصيل كل طبيب
- سجل الزيارات السابقة لكل طبيب

### 3️⃣ إضافة طبيب جديد
- نموذج منظم وسهل الاستخدام
- تحقق من صحة البيانات

### 4️⃣ إضافة زيارة جديدة
- اختيار الطبيب من قائمة منسدلة
- منتقي التاريخ للزيارة
- تسجيل الأصناف المعروضة والعينات
- تاريخ المتابعة القادمة

## 🛠️ التقنيات المستخدمة

- **Flutter 3.10+** - إطار العمل
- **Firebase Firestore** - قاعدة البيانات
- **GetX** - إدارة الحالة
- **Intl** - دعم اللغة العربية

## 🚀 البدء السريع

### المتطلبات
- Flutter 3.10+
- Dart 3.0+
- Firebase Account

### التثبيت

1. استنساخ المشروع:
```bash
git clone https://github.com/muhmoud157-prog/mandubi.git
cd mandubi
```

2. تثبيت الحزم:
```bash
flutter pub get
```

3. إعداد Firebase:
   - أنشئ مشروع Firebase جديد
   - فعّل Firestore Database
   - حدّث `lib/firebase_options.dart` ببيانات Firebase

4. تشغيل التطبيق:
```bash
flutter run
```

## 📊 قاعدة البيانات

### جدول الأطباء (Doctors)
- اسم الطبيب
- التصنيف (A, B, C)
- التخصص
- العيادة/المستشفى
- المنطقة
- رقم الهاتف
- ملاحظات الصيدليات

### جدول الزيارات (Visits)
- الطبيب (ربط)
- تاريخ الزيارة
- الأصناف المعروضة
- العينات المقدمة
- ملخص الزيارة
- تاريخ المتابعة القادمة
